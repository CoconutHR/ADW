# 实施计划：AxData 买卖时机分析面板

> 依据需求文档：`.agent/axdata-trade-panel/requirements.md`
> 技术形态：纯静态页面（原生 ESModule + ECharts CDN 按需引入），入口 `index.html`，直连 AxData HTTP API

- [ ] 1. 搭建项目骨架与页面框架
   - 创建 `index.html` 入口、`css/` 样式、`js/` 模块目录结构
   - 实现哈希路由（配置页 / 个股分析 / 自选扫描 / 市场情绪 / 回验）与顶部导航
   - 建立本地存储工具（配置与自选股的读写封装）
   - _需求：9.1、9.2_

- [ ] 2. 实现 AxData 数据适配层
   - 编写统一请求模块：默认按 `POST /v1/request/{接口名}` 约定封装接口名、`params`、`fields`，含超时控制（10 秒）与可读错误信息（含 Provider 名称与重试入口）
   - 实现请求路径模板可配置（默认 Base URL `http://127.0.0.1:8666`，local open 免 token；用户可在配置页覆盖），接口细节与页面逻辑解耦
   - 实现受限并发请求调度器（供批量扫描复用）
   - _需求：1.1、1.3、1.4、1.5、9.5_

- [ ] 3. 实现配置页与连通性测试
   - 编写 AxData 服务地址配置表单（默认 `http://127.0.0.1:8666`），持久化到本地存储
   - 实现"测试连接"功能：调用 `GET /health` 验证连通性并反馈成败原因
   - 提供 CORS / 反向代理配置指引文案，处理跨域失败提示（含 HTTPS 页面访问本机 HTTP 服务的混合内容/私有网络限制说明）
   - 实现演示数据模式：AxData 不可达时以内置模拟数据驱动完整界面（K线、信号、评分），顶部明确标注"演示数据"
   - _需求：1.1、1.2、1.3、9.3、9.6_

- [ ] 4. 编写技术指标计算库
   - 编写纯 JS 计算：MA(5/10/20/60)、MACD、RSI、KDJ、BOLL
   - 处理数据不足场景（K 线根数不够时跳过并返回"数据不足"标记）
   - _需求：3.1、3.5_

- [ ] 5. 编写信号识别引擎
   - 编写信号识别：MACD 金叉/死叉、RSI 超买超卖、KDJ 金叉/死叉、均线多空排列、量价背离
   - 输出结构化信号列表（方向、类型、触发位置、触发理由），多空冲突时并列保留双方信号
   - 编写信号引擎单元自测（用构造数据验证交叉与背离判定正确性）
   - _需求：3.2、3.3_

- [ ] 6. 实现个股分析视图（K 线图表页）
   - 通过适配层拉取 K 线与实时快照，实现 ECharts K 线主图 + 成交量副图（红涨绿跌），支持 MA/MACD/KDJ/BOLL 叠加开关
   - 实现十字光标明细（OHLC、涨跌幅、成交量）、周期切换、加载占位
   - 在 K 线图上标注信号点，侧栏展示信号列表与触发理由；同屏展示实时快照条
   - _需求：2.1、2.2、2.3、2.4、2.5、3.2、3.4_

- [ ] 7. 实现五维时机评分与框架性建议面板
   - 编写五维评分模块：趋势、动量、量能、波动率、位置（支撑/压力相对位置），每维输出得分与依据
   - 实现加权综合评分与三态结论（偏多/中性/偏空），附完整触发条件清单与权重明细，评分规则可查看
   - 偏多/偏空时输出参考价位（支撑、压力、关注/止损参考位）并标注"由历史数据推算，仅供参考"；关键数据缺失时降级评分并标注缺口；同屏展示免责声明
   - _需求：4.1、4.2、4.3、4.4、4.5、4.6_

- [ ] 8. 集成 AxData 特色短线指标与市场情绪视图
   - 实现个股特色指标卡片（竞价昨比、开盘量比、开盘换手、自由流通市值等），Provider 不可用时优雅降级为占位提示
   - 实现市场情绪页：连板天梯、题材强度视图（数据可用时）
   - 将特色指标纳入短线评分维度，参与综合时机评估
   - _需求：5.1、5.2、5.3、5.4_

- [ ] 9. 实现自选股管理与批量扫描页
   - 实现自选股增删、本地持久化、即时刷新
   - 实现批量扫描：受限并发逐只拉取并计算信号与评分，展示进度、支持中途取消
   - 实现结果表：按综合评分、信号方向、涨跌幅排序筛选，点击行跳转个股详情
   - _需求：6.1、6.2、6.3、6.4_

- [x] 10. 实现历史信号回验页
   - 实现回验参数表单（时间区间、信号类型、持有天数 N）
   - 实现统计引擎：信号触发后 N 日收益分布，输出触发次数、胜率、平均/中位收益、最大单笔亏损
   - 数据不足时明确提示，结果附样本量说明，避免小样本误读
   - _需求：7.1、7.2、7.3、7.4_

- [x] 11. 全局收尾：响应式与整体联调
   - 页脚仅一行小字标注数据来源（AxData、仅供个人研究），加入 With 签名行，不构建额外合规展示
   - 响应式适配：桌面主要内容区占宽 80% 以上，移动端单列布局
   - 整体联调自测：配置→拉数→图表→评分→扫描→回验全链路走通，验证错误场景（服务不可达、Provider 缺失、停牌空数据）均优雅降级
   - _需求：8.1、8.2、9.4、1.3_
